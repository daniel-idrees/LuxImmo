# Testing the Screens

This skill is about automatically checking that the app's screens look and behave correctly — by running them and verifying what is shown on the display. These checks run on a phone or emulator, so they exercise the real user interface.

## Technical details

The setup and conventions for these on-device screen tests live in [`references/details.md`](references/details.md). A generic worked example is in [`examples/`](examples/).
