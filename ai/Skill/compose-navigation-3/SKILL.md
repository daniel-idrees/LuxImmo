# Moving Between Screens

This skill covers how the app takes the user from one screen to another in a structured, mistake-resistant way that is kept separate from the rest of the screen logic. Keeping navigation in its own place makes screens simpler and journeys easier to change.

## Technical details

The conventions for defining destinations and performing navigation live in [`references/details.md`](references/details.md). A generic worked example (the "Articles" feature's navigation) is in [`examples/`](examples/).
