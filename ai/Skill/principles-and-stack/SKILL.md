# Principles & Tech Stack

This skill explains the thinking behind how the app is built and the specific set of tools chosen to build it. It answers two questions: what core ideas guide the way the app is put together, and which technologies are used for each job — the programming language, the libraries for screens, data, and background work, and the build tooling.

Use it to get oriented before diving into any specific area, or when deciding which tool to reach for.
